Instructions:

1. **Trust SymPy when it decided.** If SymPy says a line does NOT follow from the line before, the first such line is where the student went wrong. Do not argue with it.
2. **verdict** (always give one):
   - `correct`: the final answer is right and every line is right.
   - `correct_with_flaw`: the final answer is right, but some line is wrong (two mistakes cancel out).
   - `incomplete`: the value equals the reference but is not in the form asked for (for example, not fully factored).
   - `incorrect`: the final answer is wrong, or there is no real answer.
3. **error_type**: `null` only when the verdict is `correct`. Otherwise look at the **first wrong line** only and ask these questions in order; the first "yes" is the answer:
   1. Is there no answer, or only the problem copied, or "I don't know"? → `no_answer`
   2. Would flipping the sign (+/−) of one single term make that line right? → `sign`. A hint `sign_flip_detected: line n` from code means SymPy confirmed this for line n.
   3. Is the mistake in knowledge expected before this course (algebra, fractions, exponents, trigonometric identities, log rules)? → `prerequisite`. Example: ln(a+b) = ln a + ln b.
   4. Did the student choose a method that cannot work for this kind of problem? → `wrong_method`. Examples: L'Hôpital on a limit that is not 0/0 or ∞/∞; setting f'(x) = 0 to find inflection points, or f''(x) = 0 to find critical points.
   5. Is a rule of this topic misunderstood (wrong formula, a forgotten step such as the chain rule, an answer not in the asked form)? → `concept`. Every `incomplete` answer is `concept`.
   6. None of the above: the method and the rule are right, but arithmetic slipped. → `calculation`. Example: 3 · 4 = 7.
   If unsure between `concept` and `calculation`, ask: "If the student did this problem again, would they make the same mistake?" Same mistake → `concept`; probably right next time → `calculation`.
4. **first_wrong_line**: the number of the first line that contains a mistake, even if later lines follow correctly from it. `null` when the verdict is `correct` or `incomplete`, or the error type is `no_answer`. When every line follows from the one before but the final answer is still wrong, the mistake is a wrong choice (for example, which derivative to set to zero): give the line where that choice was made.
5. **evidence**: one short sentence in Thai that names the line and what went wrong, for example "บรรทัด 2: −3 กลายเป็น +3". Use an empty string when the verdict is `correct`.
6. **method**: `other` when the answer is right but uses a method different from the course sheet; otherwise `doc`. If no course method is given, answer `doc`.
7. **confidence**: how sure you are of your verdict and first_wrong_line, from 0 to 1. It matters most when SymPy could not decide.
8. Return only JSON matching this schema, with no other text:

{"error_type": "calculation | sign | wrong_method | concept | prerequisite | no_answer | null", "evidence": "string", "method": "doc | other", "verdict": "correct | correct_with_flaw | incomplete | incorrect", "first_wrong_line": "integer from 1, or null", "confidence": "number from 0 to 1"}
