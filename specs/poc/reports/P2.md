## 2. วิธีทดสอบ

- **Data:** golden set 50 คำตอบ (`evals/answers/labels.jsonl`) · 30 ข้อจากรูปลายมือของ 5 คน (บรรทัดคำตอบใช้เฉลยลายมือของ P1 คือถือว่าผู้ใช้ยืนยันบรรทัดแล้วตาม AM-02) · 20 ข้อเป็นคำตอบพิมพ์ (writer `w06`) เขียนให้ครบทุก error type ตามโควตา · `expression` 30, `equation` 11, `factored` 9 · verdict: `incorrect` 24, `correct` 22, `incomplete` 2, `correct_with_flaw` 2
- **Label:** ทีม (May + Jam) ตกลงให้ AI (Claude) ร่าง label ทั้ง 50 ข้อและคำตอบพิมพ์ 20 ข้อ (PR #52 · `evals/answers/worksheet.md`) ตามคู่มือใน `evals/README.md` · May ตรวจและยืนยันทุกข้อ (`labeled_by: May`) · Jam ไม่ได้ label เพราะเป็นคนทำ checker
- **ขั้นตอน:** แต่ละข้อผ่าน pipeline เดียวกับที่ห้องติวจะใช้ คือ SymPy ตรวจรายบรรทัด → hint `sign_flip_detected` → `ai.call("check_answer")` (tier `mid` = `vertex:gemini-3.5-flash` location `global`, temperature 0, `thinking: low`) → merge rules · ให้คะแนนด้วย `run_eval.py` ตามนิยามที่ทีมตกลง (PR #47): verdict หารด้วย 50 ข้อ · error_type หารด้วย 28 ข้อที่ label ไม่ใช่ `correct` · first_wrong_line หารด้วย 24 ข้อที่ label มีเลขบรรทัด
- **สิ่งที่ไม่ได้ทดสอบ:** อ่านลายมือจากรูปจริงต่อกับ checker (ใช้บรรทัดที่ label ไว้ ไม่ใช่ผล OCR) · `method` (`doc`/`other`) เพราะไม่มีวิธีของชีทใน golden set และไม่อยู่ในเกณฑ์ P2 · model อื่นนอกจาก Gemini flash · เวลาต่อข้อของ pipeline เต็มและค่าใช้จ่ายจริง (`run_checker.py` ไม่ได้จดไว้) · version ของ model ที่ Vertex ตอบจริง (prediction ไม่ได้เก็บ)
