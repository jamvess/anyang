## เกณฑ์เลือกวิชา pilot

ต้องมีทุกข้อ

1. **เป็นวิชาคณิตที่ SymPy ตรวจได้** เช่น calculus, พีชคณิต, สมการเชิงอนุพันธ์ ตอบเป็นนิพจน์หรือสมการ ไม่ใช่วิชาที่ตอบเป็นการพิสูจน์ยาวๆ เพราะ P1 และ P2 จะใช้วิชาเดียวกันต่อ
2. **ชีทเป็นภาษาไทยหรือไทยปนอังกฤษ** เพราะ P3 ต้องการรู้ว่าอ่าน PDF ภาษาไทยได้ดีแค่ไหน
3. **มีข้อสอบเก่าอย่างน้อย 2 ชุดที่มีเลขข้อชัดเจน** เพราะต้อง map ทีละข้อ (`midterm-2567-1:Q3`) โดยไม่ต้องมีเฉลย
4. **ชีทครอบคลุมเนื้อหาของข้อสอบทั้ง 2 ชุด** ถ้าข้อสอบออกบทที่ชีทไม่มี จะวัดผลไม่ได้

ถ้าได้จะดีมาก

5. **ข้อสอบ 2 ชุดมาจากอาจารย์คนละคน** P3 จะได้วัดว่าหัวข้อซ้อนกันกี่ % เพื่อตั้งค่า `stars.weight_other_instructor` (ตอนนี้ใช้ 0.5 ซึ่งยังเป็นค่าเดา [C] ดู `learning-model.md`)
6. **มีทั้ง PDF ที่เลือกข้อความได้และไฟล์สแกน** อย่างละอย่างน้อย 1 ไฟล์ เพื่อทดสอบทั้งสองทาง (ai-orchestration §2.3)
7. **มีเพื่อนในทีมเคยเรียนวิชานี้** คนที่ label หัวข้อจะได้ตัดสินเรื่องดาวได้ถูก
8. **ชีทไม่ยาวเกิน ~150 หน้า** ทั้งเพื่อให้ label ทันก่อน 23 ต.ค. และเพื่อคุมค่า API ตอนรัน PoC

## กติกาไฟล์

- **ไฟล์จริงไม่ขึ้น git** เพราะเป็นลิขสิทธิ์ของอาจารย์ และ repo อาจเปิด public ภายหลัง ให้เก็บต้นฉบับใน Drive ทีมที่ `anyang-evals/topics/<subject>/` และก๊อปมาไว้ที่ `raw/` บนเครื่อง (`.gitignore` มี `evals/**/raw/` อยู่แล้ว)
- **ตั้งชื่อไฟล์:** `sheet.pdf` (ถ้ามีหลายไฟล์ใช้ `sheet-01.pdf`, `sheet-02.pdf`) และ `<midterm|final|quiz>-<ปี พ.ศ.>-<ภาค>.pdf` ชื่อไฟล์ข้อสอบ (ไม่รวม `.pdf`) คือ prefix ที่ใช้ใน `question_map` ของ `labels.json`
- **ลบชื่อนักศึกษาออก** ถ้าเป็นข้อสอบที่มีคนเขียนตอบแล้ว ให้ใช้ไฟล์โจทย์เปล่า หรือปิดชื่อและคำตอบก่อนอัปโหลด
