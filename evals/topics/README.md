## เกณฑ์เลือกวิชา pilot

ต้องมีทุกข้อ

1. **เป็นวิชาคณิตที่ SymPy ตรวจได้** เช่น calculus, พีชคณิต, สมการเชิงอนุพันธ์ ตอบเป็นนิพจน์หรือสมการ ไม่ใช่วิชาที่ตอบเป็นการพิสูจน์ยาวๆ เพราะ P1 และ P2 จะใช้วิชาเดียวกันต่อ
2. **ชีทเป็นภาษาไทยหรือไทยปนอังกฤษ** เพราะ P3 ต้องการรู้ว่าอ่าน PDF ภาษาไทยได้ดีแค่ไหน
3. **มีข้อสอบเก่าอย่างน้อย 2 ชุดที่มีเลขข้อชัดเจน** เพราะต้อง map ทีละข้อ (`midterm-2567-1:Q3`) โดยไม่ต้องมีเฉลย
4. **ชีทครอบคลุมเนื้อหาของข้อสอบทั้ง 2 ชุด** ถ้าข้อสอบออกบทที่ชีทไม่มี จะวัดผลไม่ได้

ถ้าได้จะดีมาก

5. **ข้อสอบ 2 ชุดมาจากอาจารย์คนละคน** P3 จะได้วัดว่าหัวข้อซ้อนกันกี่ % เพื่อตั้งค่า `stars.weight_other_instructor` (ตอนนี้ใช้ 0.5 ซึ่งยังเป็นค่าเดา [C] ดู `learning-model.md`)
6. **มีทั้ง PDF ที่เลือกข้อความได้และไฟล์สแกน** อย่างละอย่างน้อย 1 ไฟล์ เพื่อทดสอบทั้งสองทาง (ai-orchestration §2.3)
7. **มีเพื่อนในทีมเคยเรียนวิชานี้** คนที่ label หัวข้อจะได้ตัดสินเรื่องดาวได้ถูก
8. **ชีทไม่ยาวเกิน ~150 หน้า** ทั้งเพื่อให้ label ทันก่อน 23 ต.ค. และเพื่อคุมค่า API ตอนรัน PoC

## กติกาไฟล์

- **ไฟล์จริงไม่ขึ้น git** เพราะเป็นลิขสิทธิ์ของอาจารย์ และ repo อาจเปิด public ภายหลัง ให้เก็บต้นฉบับใน Drive ทีมที่ `anyang-evals/topics/<subject>/` และก๊อปมาไว้ที่ `raw/` บนเครื่อง (`.gitignore` มี `evals/**/raw/` อยู่แล้ว)
- **ตั้งชื่อไฟล์:** `sheet.pdf` (ถ้ามีหลายไฟล์ใช้ `sheet-01.pdf`, `sheet-02.pdf`) และ `<midterm|final|quiz>-<ปี พ.ศ.>-<ภาค>.pdf` ชื่อไฟล์ข้อสอบ (ไม่รวม `.pdf`) คือ prefix ที่ใช้ใน `question_map` ของ `labels.json`
- **ลบชื่อนักศึกษาออก** ถ้าเป็นข้อสอบที่มีคนเขียนตอบแล้ว ให้ใช้ไฟล์โจทย์เปล่า หรือปิดชื่อและคำตอบก่อนอัปโหลด

## คู่มือ label · `labels.json`

ผลที่ได้คือ "คำตอบที่ถูก" ไว้เทียบกับ output ของ pipeline P3 รูปแบบจึงตรงกับ output ของ A5, A6 และ A7 (`specs/system/ai-orchestration.md` §2.3.4) เพื่อเอามาเทียบกันได้ตรงๆ

**ใครทำ:** May label · Junior ตรวจ · Jam ไม่แก้ไฟล์ label เพราะ Jam เป็นคนทำ P3 (กฎ "คน label ไม่ใช่คนทำ PoC" ใน `evals/README.md`) ถ้าไม่แน่ใจ ถาม Jam ได้ แต่คนเขียนลงไฟล์ต้องเป็นคน label

**ห้ามใช้ AI ช่วย label** ห้ามให้ Claude, Gemini หรือ ChatGPT สกัดหัวข้อหรือ map ข้อสอบให้ เพราะ label ที่ได้จะเหมือน output ของ AI และ P3 จะวัดอะไรไม่ได้ ใช้ AI ได้แค่ช่วยแปลง JSON ที่เขียนเองแล้ว

**อย่าเปิดตาราง "ข้อสอบแต่ละข้ออยู่ในชีทไหน" ใน `sources.md` ก่อน label เสร็จ** ตารางนั้น Claude เป็นคนเขียน ถ้าเห็นก่อน label จะถูกชี้นำ

### ขั้นตอน

1. **อ่านชีทแล้วแบ่งหัวข้อ** ตามลำดับในชีท จดหน้าเริ่มและหน้าจบของแต่ละหัวข้อ
2. **เขียน skills ของแต่ละหัวข้อ** 2–5 skill
3. **ใส่ prereqs** คือหัวข้อที่ต้องรู้ก่อน
4. **map ข้อสอบทีละข้อย่อย** แต่ละข้อย่อยมี 1 หัวข้อ + 1 skill ถ้าไม่มีหัวข้อไหนเข้า ให้ใส่ใน `unmapped`
5. **ให้ดาว** ทีละหัวข้อ (ทำหลังสุด หลังจาก map ข้อสอบครบแล้ว)

### หัวข้อ · ขนาดกลาง

1 หัวข้อ = สิ่งที่ติวจบได้ใน 1 session (30–60 นาที) และมีโจทย์ได้หลายแบบ

| | ตัวอย่าง (วิชาอื่น) | |
|---|---|---|
| หยาบไป | "อินทิเกรต" | ทั้งบท ติว session เดียวไม่จบ |
| **พอดี** | "การอินทิเกรตทีละส่วน (integration by parts)" | |
| ละเอียดไป | "อินทิเกรต x·eˣ" | นี่คือโจทย์แบบหนึ่ง ให้ใส่เป็น skill |

- ตั้งชื่อตามที่ชีทใช้ ถ้าชีทมีศัพท์อังกฤษกำกับ ให้ใส่ไว้ในวงเล็บ
- ถ้าเรื่องเดียวกันอยู่หลายไฟล์ ให้เป็นหัวข้อเดียว แล้วใส่ `pages` ทุกช่วง
- หัวข้อที่อยู่ในชีทแต่ไม่เคยออกสอบ ต้องใส่ด้วย (จะได้ ★)
- เนื้อหาที่เป็นแค่การทบทวนสั้นๆ หรือตารางสูตร ไม่ต้องตั้งเป็นหัวข้อ

### Skill

skill = **โจทย์แบบหนึ่งที่ผู้เรียนต้องทำได้** เขียนขึ้นต้นด้วยคำกริยา เช่น "หา ∫ ของพหุนามคูณ eˣ ที่ต้องใช้ทีละส่วนซ้ำหลายครั้ง" ไม่ใช่ "integration by parts ขั้นสูง"

ทดสอบว่าเขียน skill ถูกไหม: ถ้าอ่านชื่อ skill แล้วแต่งโจทย์ใหม่ได้ 1 ข้อทันที ถือว่าใช้ได้

### map ข้อสอบ

- **เลขข้อ:** `<ไฟล์>:<หมวด><ข้อ>.<ข้อย่อย>` เช่น `midterm-2559-1:ค2.3` · ข้อที่ไม่มีข้อย่อยใช้ `midterm-2561-1:ก4`
- 1 ข้อย่อย = 1 หัวข้อ + 1 skill ถ้าข้อย่อยใช้หลายเรื่อง ให้เลือก **เรื่องที่ข้อนั้นตั้งใจวัด** เช่น ข้อหาค่าสุดขีดที่ต้อง diff ก่อน → หัวข้อค่าสุดขีด ไม่ใช่หัวข้อกฎการหาอนุพันธ์
- ถ้าเป็นข้อปรนัยแบบตาราง (เช่น 2559 ข2 ที่ให้เลือก f = g' ทั้ง 5 ข้อย่อย) ให้ map ทุกข้อย่อย
- `trap` (ไม่บังคับ): กับดักที่ทำให้คนทำผิดบ่อย เช่น "ลิมิตด้านซ้าย |x| = −x" ถ้าไม่เห็นกับดักชัด ให้ใส่ `null`
- ถ้าไม่มีหัวข้อไหนในชีทที่เข้ากับข้อนั้น ให้ใส่ใน `unmapped` พร้อมเหตุผล และห้ามสร้างหัวข้อใหม่ขึ้นมาเพื่อข้อนั้น

### ดาว · `stars_human`

ตอบคำถามนี้ทีละหัวข้อ: **"ถ้าคุณเป็นรุ่นพี่ จะบอกน้องที่กำลังจะสอบกลางภาคว่าหัวข้อนี้สำคัญแค่ไหน"** โดยดูข้อสอบเก่าประกอบ

| | ความหมาย |
|---|---|
| 3 | ต้องทำได้แน่ๆ ออกแทบทุกครั้ง หรือคะแนนเยอะ |
| 2 | ควรทำได้ ออกบ้าง หรือเป็นพื้นฐานของหัวข้อ 3 ดาว |
| 1 | อ่านถ้ามีเวลา |

ไม่ต้องคำนวณตามสูตรในสเปก script จะคำนวณเองแล้วเอามาเทียบกับดาวที่คุณให้ ถ้าคุณให้ดาวตามสูตร P3 จะทดสอบไม่ได้ว่าสูตรตรงกับความรู้สึกของคนไหม

### รูปแบบไฟล์

```json
{
  "subject": "mth10101",
  "labeled_by": "May",
  "reviewed_by": "Junior",
  "topics": [
    {
      "id": "t01",
      "name": "การอินทิเกรตทีละส่วน (Integration by Parts)",
      "pages": ["sheet-03:12-25"],
      "prereqs": ["t00"],
      "skills": [
        {"id": "t01.s1", "name": "หา ∫u dv เมื่อ u เป็นพหุนามและ dv เป็นเอกซ์โพเนนเชียลหรือตรีโกณ"},
        {"id": "t01.s2", "name": "หา ∫ ที่ต้องใช้ทีละส่วนซ้ำจนได้อินทิกรัลเดิมกลับมา"}
      ],
      "stars_human": 3
    }
  ],
  "question_map": {
    "midterm-2567-1:ข3.1": {"topic": "t01", "skill": "t01.s1", "trap": "ลืมบวกค่าคงที่ C"}
  },
  "unmapped": {
    "midterm-2567-1:ค1": "ถามเรื่องอนุกรมเทย์เลอร์ ซึ่งไม่มีในชีท"
  }
}
```

- ลำดับใน `topics` คือลำดับในชีท และใช้เทียบกับ `order` ของ A6
- `id` ของ topic และ skill ตั้งอะไรก็ได้ แต่ห้ามซ้ำ และห้ามเปลี่ยนหลังจาก map ข้อสอบแล้ว
- `pages` ใช้รูปแบบ `<ไฟล์>:<หน้าแรก>-<หน้าสุดท้าย>` ใช้เลขหน้าของ PDF (ที่ตัวอ่าน PDF แสดง) ไม่ใช่เลขที่พิมพ์อยู่บนกระดาษ
- ทุกข้อย่อยของข้อสอบต้องอยู่ใน `question_map` หรือ `unmapped` อย่างใดอย่างหนึ่ง
- ไม่ต้อง label `common_mistakes` ของ A6 เพราะคนเดาเองได้ไม่แม่น

### ข้อสอบ held-out

label ของข้อสอบ held-out (เช่น MTH10101 ปี 2562) **ห้าม commit** เพราะแค่ map หัวข้อก็บอกได้แล้วว่าหัวข้อไหนออกสอบ ให้เก็บเป็น `labels-holdout.json` ในโฟลเดอร์ held-out บน Drive จนกว่าคนที่จะทำข้อสอบจะทำเสร็จ
