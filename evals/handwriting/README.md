# handwriting/ · รูปลายมือสำหรับ P1

ชุดรูปลายมือคณิตที่ใช้วัดว่า AI อ่านลายมือเป็น LaTeX รายบรรทัดได้แม่นแค่ไหน (P1 ใน `specs/poc/README.md`) · ใน S3 จะนำรูปชุดเดียวกันไปใช้เป็น golden set คำตอบของ P2 ด้วย

ไฟล์นี้อธิบายวิธี**เก็บรูป** ส่วนวิธี **label** (พิมพ์ LaTeX รายบรรทัด) ดูใน `evals/README.md` หัวข้อ "คู่มือ label ลายมือ · P1"

```
handwriting/
├─ README.md        # ไฟล์นี้
├─ problems.md      # โจทย์ที่ให้คนเขียนทำ (P01, P02, ...)
├─ consent.md       # ข้อความขอความยินยอม + template ตารางรหัสคนเขียน
├─ photos.csv       # รูปไหนใครเขียน ทำโจทย์ข้อไหน (ใช้แค่รหัส ไม่มีชื่อจริง)
├─ make_labels.py   # สร้าง labels.jsonl แบบโครงจาก photos.csv (test: test_make_labels.py)
├─ crop_screenshots.py  # crop ภาพแคปหน้าจอ tablet ให้เหลือแค่ลายมือ
├─ labels.jsonl     # เฉลย LaTeX รายบรรทัด (May พิมพ์)
└─ raw/             # รูปจริง · gitignored · ต้นฉบับอยู่ใน Drive ทีม
```

## เป้าของชุดรูป

| เรื่อง | เป้า | ทำไม |
|---|---|---|
| จำนวนรูป | ≥ 30 (ถ้าได้ถึง 50 ยิ่งดี) | ตามขนาดข้อมูลของ P1 |
| จำนวนคนเขียน | ≥ 5 คน และไม่เกิน 10 รูปต่อคน | ไม่ให้ลายมือของคนใดคนหนึ่งมีน้ำหนักมากเกินไป |
| `answer_format` | แต่ละแบบ ≥ 5 รูป (expression, factored, equation) | P2 ต้องใช้ทั้ง 3 แบบ |
| มีบรรทัดที่ผิด | ≥ 8 รูป | P2 ต้องมีคำตอบผิดไว้ให้ตรวจ และ P1 ต้องดูว่า AI ไม่แอบแก้คำตอบที่ผิดให้ถูก |
| มีการขีดฆ่า | ≥ 3 รูป | ทดสอบกติกาข้อ "ข้ามบรรทัดที่ขีดฆ่า" ของ prompt |
| อุปกรณ์ | มีทั้งปากกาและดินสอ | ดินสอจางกว่า อ่านยากกว่า |

## ใครเขียนอะไร

P1 ต้องการลายมือที่หลากหลาย ไม่ได้ต้องการให้คนเขียนทำโจทย์เป็น จึงให้คนเขียนทั้ง 5 คน (Jam, Junior, May และเพื่อนนอกทีม 2 คน) **ลอก**วิธีทำจาก "ใบลอก" ที่เตรียมไว้คนละ 6 รูป รวม 30 รูป · บางใบตั้งใจให้มีบรรทัดผิดหรือมีบรรทัดที่ต้องขีดฆ่า · ถ้าอยากได้มากกว่า 30 รูป ให้ทำโจทย์เองจาก `problems.md` เพิ่ม โดยไม่เกิน 10 รูปต่อคน

- ใบลอกของ **May เป็นฉบับที่ถูกทั้งหมด** เพราะ May เป็นคน label error type ถ้าได้ลอกใบที่ผิดเองจะรู้คำตอบล่วงหน้า
- Jam เขียนได้ เพราะกติกา "คน label ไม่ใช่คนทำ PoC" ห้ามแค่การ label
- ใบลอก, ไฟล์ที่ใช้สร้างใบลอก และเฉลยว่าใบไหนตั้งใจให้ผิดแบบไหน **เก็บใน Drive เท่านั้น** ห้าม commit · เฉลยนี้ใช้ตรวจ label ของ May ในภายหลัง

### สิ่งที่ได้จริง (19 ต.ค. 2569)

ได้ครบ 30 รูป เลขข้อตรงกับใบลอกครบ แต่**ไม่มีใครเขียนบนกระดาษ** · ทุกคนเขียนบน tablet

| คนเขียน | `medium` | ทำอะไรต่อ |
|---|---|---|
| w03, w04, w05 | `tablet_screenshot` (แคปหน้าจอแอปจดโน้ต มีแถบเครื่องมือติดมา) | crop ด้วย `crop_screenshots.py` |
| w02 | `tablet_screenshot` (crop มาเองแล้ว ภาพเล็ก ~950 px) | ใช้ตามเดิม |
| w01 | `screen_photo` (ใช้มือถือถ่ายหน้าจอ tablet มี moiré และเงาสะท้อน) | ใช้ตามเดิม |

ชุดนี้จึงวัดได้แค่ "ลายมือบน tablet" · ใน report P1 ต้องเขียนว่ายังไม่ได้วัดกับรูปถ่ายกระดาษ · ถ้ามีเวลา ควรเก็บรูปกระดาษ (`medium: paper`) เพิ่มอีกประมาณ 10 รูป ทั้งปากกาและดินสอ

## วิธีถ่ายรูป (ส่งให้คนเขียนอ่าน)

1. **1 รูป = 1 ข้อ** · เขียนเลขข้อ (เช่น `P05`) ไว้มุมบนของกระดาษ
2. ถ้าใช้ใบลอก: ลอกทีละบรรทัดให้เหมือนทุกตัว แม้บางบรรทัดจะดูแปลกก็ไม่ต้องแก้ · บรรทัดที่บอกให้ขีดฆ่า ให้เขียนก่อนแล้วค่อยขีดฆ่าทิ้ง · ถ้าทำโจทย์เอง: เขียนวิธีทำแบบที่ทำการบ้านตามปกติ **ถ้าทำผิดก็ไม่ต้องแก้** ถ้าอยากเปลี่ยนก็ขีดฆ่าได้
3. **ห้ามเขียนชื่อหรือรหัสนักศึกษา**ลงบนกระดาษ
4. ถ่ายด้วยกล้องมือถือแบบที่ปกติถ่ายส่งงาน: ถ่ายจากด้านบนให้เห็นวิธีทำครบทุกบรรทัด และคนอ่านรูปแล้วอ่านออก · ไม่ต้องใช้แอปสแกนหรือฟิลเตอร์
5. ส่งรูปเป็นไฟล์ต้นฉบับ (ใน LINE ให้เลือก "ส่งรูปต้นฉบับ" หรืออัปโหลดเข้า Drive) ไม่ส่งรูปที่ถูกบีบอัด

## ที่เก็บรูป

- ต้นฉบับเก็บใน Drive ทีม โฟลเดอร์ `evals/handwriting/` ซึ่งแบ่งเป็น 2 โฟลเดอร์ย่อย
  - `inbox/`: รูปที่คนเขียนส่งมา ยังใช้ชื่อไฟล์เดิม
  - `raw/`: รูปที่เปลี่ยนชื่อแล้ว (`hw_001.jpg`, `hw_002.jpg`, ...) · ก๊อปโฟลเดอร์นี้ลง `evals/handwriting/raw/` ในเครื่อง
- ตารางรหัสคนเขียน (จับคู่ `w01` กับชื่อจริง) และผลตอบของ Google Form ขอความยินยอม ให้เก็บใน Drive เท่านั้น **ห้าม commit ลง git**
- ใน git มีได้แค่ `photos.csv` และ `labels.jsonl` ซึ่งใช้แค่รหัส

## ขั้นตอน

1. ส่งลิงก์ Google Form ขอความยินยอม (ข้อความอยู่ใน `consent.md`) ให้คนเขียน · **ต้องได้คำตอบ "ยินยอม" ก่อนจึงจะรับรูป**
2. ให้รหัสคนเขียนตามลำดับที่ตอบ Form (`w01`, `w02`, ...) แล้วจดลงตารางรหัสใน Drive
3. ส่งใบลอกของแต่ละคน พร้อมหัวข้อ "วิธีถ่ายรูป" ด้านบนให้คนเขียน
4. รับรูปเข้า `inbox/<คนเขียน>/` แล้วเปลี่ยนชื่อเป็น `hw_NNN` เรียงต่อจากเลขล่าสุด ไว้ใน `raw/` และเพิ่ม 1 บรรทัดใน `photos.csv` · ถ้าเป็นภาพแคปหน้าจอที่มี UI ของแอปติดมา ให้ crop ก่อนด้วย `crop_screenshots.py` (ต้องวัด `PAGE_AREA` ของเครื่องนั้นใหม่)
5. รัน `uv run --project apps/api python evals/handwriting/make_labels.py` จาก root ของ repo เพื่อเพิ่มรูปใหม่ลงใน `labels.jsonl` (ไม่ทับบรรทัดที่ label ไปแล้ว) · ใส่ `--check` ถ้าอยากเช็คอย่างเดียวโดยไม่เขียนไฟล์

### `photos.csv`

```csv
id,writer,problem,tool,medium
hw_001,w01,P05,pen,paper
hw_002,w01,P11,stylus,tablet_screenshot
```

- `problem` คือเลขข้อใน `problems.md` · script จะดึงตัวโจทย์ LaTeX มาใส่ใน `labels.jsonl` ให้เอง
- `tool` ใส่ `pen`, `pencil` หรือ `stylus`
- `medium` (ไม่บังคับ ถ้าไม่ใส่ถือเป็น `paper`): `paper`, `tablet_screenshot` หรือ `screen_photo`
