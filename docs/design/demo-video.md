## เป้าหมาย (goal ของอาจารย์ 17 พ.ย.)

ทำ user journey ให้ครบหนึ่งลูป ใช้วิชาคณิตวิชาเดียว (MTH10101):

1. สมัครและ login ด้วย username / password (ใช้อีเมลเป็น username · D1)
2. สร้างการเตรียมสอบ (ชื่อวิชา วันสอบ)
3. อัปโหลดชีท แล้วระบบแสดงหัวข้อที่สกัดได้
4. บันทึกการเรียนลงฐานข้อมูล ปิดแล้วกลับมาเรียนต่อได้

## บทพูด (ร่าง · May ปรับเป็นคำของตัวเองได้)

0. "อ่านยัง? คือห้องติวสอบที่มี AI ติวเตอร์ วิดีโอนี้เดิน user journey ครบหนึ่งลูปด้วยวิชาคณิต MTH10101 ตาม 4 goal นี้ ทุกขั้นรันจริงบนฐานข้อมูลและ AI จริง"
1. "เริ่มจากผู้ใช้ใหม่ สมัครด้วยอีเมลและรหัสผ่าน เข้าระบบได้ทันที ลองออกจากระบบแล้วเข้าใหม่ด้วยบัญชีเดิม"
2. "สร้างการเตรียมสอบ ใส่ชื่อวิชาและวันสอบ ระบบนับวันที่เหลือให้"
3. "อัปโหลดชีทและข้อสอบเก่า ระบบเดาประเภทไฟล์ให้ยืนยัน แล้วอ่านไฟล์เบื้องหลัง (ตัดช่วงรอจริง n นาที) ได้หัวข้อพร้อมดาวความสำคัญที่คำนวณจากข้อสอบเก่า ผู้ใช้ยืนยันขอบเขต"
4. "เข้าห้องติว ติวเตอร์เลือกหัวข้อดาวสูงที่ยังอ่อนให้ก่อน ให้โจทย์ที่ SymPy ตรวจเฉลยแล้ว ตอบพร้อมวิธีทำ ระบบตรวจด้วย SymPy แล้วบันทึกคำตอบลงฐานข้อมูล"
5. "ถ้าปิดเว็บกลางทาง เปิดกลับมา แชทและโจทย์ที่ค้างยังอยู่ ตอบต่อได้เลย"
6. "จบการติว ได้สรุปสั้นๆ ในแชท เริ่มรอบใหม่ การ์ดความคืบหน้าเปลี่ยนตามที่เพิ่งทำ ข้อมูลทั้งหมดอยู่ในฐานข้อมูล"
7. "สรุปสถานะ 4 goal และสิ่งที่จะทำต่อ"
