## รายละเอียดช่วง 3 · ห้องติว live

**บอกผู้ชมก่อนเริ่ม:** "ส่วนนี้รันจริงบนเครื่องนี้ AI จริง (Gemini) ตรวจด้วย SymPy จริง · ยังไม่ได้ขึ้น staging เพราะระบบ login ฝั่ง API ยังไม่เสร็จ" (ถ้าวันนั้น staging พร้อม ให้ใช้ staging แทนและตัดประโยคหลังออก)

ชุดโจทย์และหัวข้อมาจากห้องเดโม่ (`specs/features/tutor/demo-room.md` §3) · วิธีเปิดดู §12 ของไฟล์นั้น

1. เปิดห้อง → การ์ดความคืบหน้า (mastery จริง · ทุกหัวข้อยังไม่เริ่ม) → tutor ทัก 2–3 ประโยคว่าเริ่มหัวข้อไหนเพราะอะไร → การ์ดโจทย์ข้อแรก `p1` แยกตัวประกอบ $x^2-49$ (0:45)
2. พิมพ์ `(x-7)(x+7)` แล้วกด Enter → ชี้ว่าตัวอักษรไหลออกมาทีละส่วน สมการ render เป็นสูตร และ tutor ชมแล้วไปข้อถัดไปเอง (1:15)
3. ข้อ 2 (ลิมิต) กด 📷 เลือก**รูปที่เตรียมไว้ซึ่งผิด 1 บรรทัด** → การ์ด "อ่านได้แบบนี้ ถูกไหม" → กดยืนยัน → ✗ พร้อมชี้บรรทัดแรกที่ผิด แล้ว tutor อธิบายทันทีโดยไม่ให้ใบ้ (2:00)
4. ชี้ว่าไม่มีปุ่มตัวเลือกคำตอบเลย ตอบได้แค่พิมพ์ ส่งรูป หรือเขียนบน canvas ใต้การ์ดโจทย์ (โชว์ canvas แค่เปิดให้เห็น ไม่เขียนจริง) (0:30)
5. กด "ออกจากห้องติว" แล้วเข้าใหม่ → การ์ดความคืบหน้าเปลี่ยนตามที่เพิ่งทำ (ในห้องเดโม่ การ์ดขึ้นตอนเปิดห้อง และความคืบหน้าอยู่ข้าม session จนกว่าจะรีสตาร์ต API · `demo-room.md` §2 D, J) (1:00)

**ถ้า live พัง** (เน็ต, Vertex, AI ล่ม): เปิดวิดีโอที่อัดไว้ของขั้น 1–5 (อัดตอนซ้อม) · ห้ามแก้ปัญหาสดหน้าห้อง เกิน 30 วินาทีให้สลับเป็นวิดีโอทันที · AI call ครั้งแรกของแต่ละชนิดช้า 20–40 วินาที จึงต้อง warm-up ก่อนขึ้น (checklist)
