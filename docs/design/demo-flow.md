## รายละเอียดช่วง 3 · ห้องติว live

**บอกผู้ชมก่อนเริ่ม:** "ส่วนนี้รันจริงบนเครื่องนี้ ข้อมูลอยู่ในฐานข้อมูลจริง AI จริง (Gemini) ตรวจด้วย SymPy จริง · ยังไม่ได้ขึ้น staging" (ถ้าวันนั้น staging พร้อม ให้ใช้ staging แทนและตัดประโยคหลังออก)

ใช้บัญชีและการเตรียมสอบที่เตรียมไว้วันก่อน (checklist) · login ไว้ก่อนขึ้น ไม่พิมพ์รหัสหน้าห้อง · โจทย์ข้อแรกคือข้อที่ค้างไว้ และรูปผิด 1 บรรทัดเขียนไว้แล้ว

1. หน้ารายการ → การเตรียมสอบ MTH10101 → เข้าห้อง → การ์ดความคืบหน้า (mastery จริงจาก DB) → tutor ทัก 2–3 ประโยคว่าเริ่มหัวข้อไหนเพราะอะไร → การ์ดโจทย์ (ข้อที่ค้างไว้) (0:45)
2. กด 📷 เลือก**รูปที่เตรียมไว้ซึ่งผิด 1 บรรทัด** → การ์ด "อ่านได้แบบนี้ ถูกไหม" → กดยืนยัน → ✗ พร้อมชี้บรรทัดแรกที่ผิด → tutor สอนทันที (AM-07) (2:00)
3. พิมพ์คำตอบที่ถูก**พร้อมวิธีทำอย่างน้อย 2 ขั้น** (เตรียมข้อความไว้) → ชี้ว่าตัวอักษรไหลออกมาและสมการ render เป็นสูตร → ✓ → "ข้อต่อไปนะ" + การ์ดโจทย์ใหม่ · ถ้าพิมพ์ขั้นเดียว ระบบจะถามวิธีทำและไม่ไปข้อต่อไป (`checker.min_working_lines`) · ถ้าไม่มีข้อต่อไป (AI สร้างโจทย์ไม่ทัน / 429) ให้บอกผู้ชมว่าระบบกันโจทย์ที่ยืนยันเฉลยไม่ได้ แล้วไปขั้น 4 (1:15)
4. ชี้ว่าไม่มีปุ่มตัวเลือกคำตอบเลย ตอบได้แค่พิมพ์ ส่งรูป หรือเขียนบน canvas ที่ท้ายแชท (โชว์แค่ให้เห็น ไม่เขียนจริง) (0:30)
5. กด "ออกจากห้องติว" แล้วเข้าใหม่ → แชทเดิม + การ์ดโจทย์ + canvas ยังอยู่ ตอบต่อได้ (TM-13) · การ์ดความคืบหน้าไม่ขึ้นซ้ำ (UC-03 E1 · `problem-card-history.md` §10 ข้อ 3) (1:00)

**ถ้า live พัง** (เน็ต, Vertex, AI ล่ม, 429): เปิดวิดีโอสำรองของช่วง 3 (อัดตอนซ้อม) · ห้ามแก้ปัญหาสดหน้าห้อง เกิน 30 วินาทีให้สลับเป็นวิดีโอทันที · ถ้าแค่ฐานข้อมูลหรือ login มีปัญหา ใช้ห้องเดโม่ได้ (`demo-room.md` §12 · ขั้นเดิมของรอบ 2 · ไม่มีขั้น 5 แบบกลับเข้าห้องเดิม) · AI call ครั้งแรกของแต่ละชนิดช้า 20–40 วินาที จึงต้อง warm-up ก่อนขึ้น (checklist)
