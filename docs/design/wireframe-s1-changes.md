## S15 · ห้องติว · เปิดห้อง

| ก่อน | หลัง | อ้างอิง |
|---|---|---|
| ไม่มีการ์ด tutor พูดเปิดเอง | progress card ขึ้นก่อน (render จาก DB ไม่ผ่าน LLM) → tutor สรุป 2–3 ประโยค + เหตุผลที่เลือกหัวข้อ → โจทย์ข้อแรก | TM-11, TM-15, TM-02, §2.2.2 |

ข้อมูลใน card (`progress_card`): `days_left`, `passed` / `total`, `readiness` (%), รายหัวข้อ `name`, `stars`, `level` (ยังไม่เริ่ม / อ่อน / กำลังดี / ผ่าน), `review_due`

## ข้อเสนอแก้ spec (รอ Jam)

**เพิ่ม param `skill_level` ของ buddy** ค่า `below` / `same` / `above` (อ่อนกว่า / พอๆ กัน / เก่งกว่าเรานิดหน่อย)

- เหตุผล: ถ้าเพื่อนติวอ่อนกว่า ผู้ใช้จะได้อธิบายให้ฟัง (learning by teaching) ถ้าเก่งกว่านิดหน่อย ผู้ใช้ได้เห็นวิธีคิด
- ไฟล์ที่ต้องแก้ถ้าตกลง: `specs/system/ai-orchestration.md` §2.7 ตาราง Param, และ role ของ buddy ใน §2.1
- ถ้า Jam ไม่ตกลง: ตัดข้อนี้ออกจาก S05
