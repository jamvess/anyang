# 1.7 สิ่งที่ส่งมอบ (Deliverables) · ร่าง 1

## อยากเล่าอะไร (ก่อนอ่านร่าง)

- ตัวอย่างทุกเล่มแยก**ผลที่ส่งในแต่ละเทอม** → แบ่งเป็นภาคการศึกษาที่ 1 (ส่งแล้วหรือส่งพร้อมรายงานนี้) และภาคการศึกษาที่ 2

- เทียบกับสิ่งที่ proposal สัญญาไว้ ไม่ทำในหัวข้อนี้ · อยู่ใน 4.2

## 1.7 สิ่งที่ส่งมอบ

### 1.7.1 สิ่งที่ส่งมอบในภาคการศึกษาที่ 1

ตารางที่ 1.10 สิ่งที่ส่งมอบในภาคการศึกษาที่ 1

| สิ่งที่ส่งมอบ | รายละเอียด |
|---|---|
| SRS (Software Requirements Specification) | requirement 91 ข้อ แบ่งระดับความสำคัญ Must, Should และ Could พร้อม non-functional requirement และเกณฑ์วัด |
| เอกสารออกแบบระบบ | สถาปัตยกรรม · data model และ ER diagram · API specification 37 endpoint · การทำงานของ AI (AI orchestration) · learning model พร้อมที่มาของทุกค่า · กลยุทธ์การทดสอบ |
| feature specification | feature specification 47 ฉบับ แต่ละฉบับมี acceptance criteria ที่ใช้สร้าง test |
| เอกสารออกแบบหน้าจอ | wireframe 27 หน้า · use case 4 กรณีหลัก |
| รายงาน PoC | 5 ฉบับ ได้แก่ การอ่านลายมือ (P1) การตรวจคำตอบ (P2) การสกัดหัวข้อและ retrieval (P3) เวลาตอบสนองและค่าใช้จ่าย (P4) และ automated deployment (P6) |
| evaluation dataset | รูปลายมือ 30 รูป · คำตอบที่เฉลยแล้ว 50 ข้อ · หัวข้อและดาวของรายวิชานำร่อง · คำถามสำหรับวัด retrieval 20 ข้อ · test case ของการแปลงคำบรรยายบุคลิก 24 กรณี · evaluation script |
| ระบบต้นแบบ | เว็บแอปพลิเคชันที่ผู้ใช้ใช้งานได้ตั้งแต่สมัครสมาชิก อัปโหลดเอกสาร ยืนยันขอบเขต ติวในห้องสนทนา ส่งคำตอบ จนจบการติวและกลับมาติวต่อ ทำงานบนเครื่องของทีมร่วมกับฐานข้อมูลบนคลาวด์ |
| source code และ test | repository พร้อม automated test มากกว่า 2,600 test case และ automated deployment ของ API ขึ้น staging |
| วิดีโอสาธิต | การใช้งานตั้งแต่ต้นจนจบตามที่อาจารย์ที่ปรึกษากำหนด |
| รายงานและการนำเสนอความก้าวหน้า | รายงานฉบับนี้และสไลด์นำเสนอ |

### 1.7.2 สิ่งที่ส่งมอบในภาคการศึกษาที่ 2

ตารางที่ 1.11 สิ่งที่ส่งมอบในภาคการศึกษาที่ 2

| สิ่งที่ส่งมอบ | รายละเอียด |
|---|---|
| ระบบฉบับสมบูรณ์ | เว็บแอปพลิเคชันที่มีความสามารถตาม requirement ระดับ Must ครบ ให้บริการบนคลาวด์ และใช้หน้าจอฉบับสมบูรณ์ |
| รายงานผลการทดสอบกับผู้ใช้ | ผลการทดสอบระยะ Alpha, Beta และ Pilot · ผลแบบทดสอบก่อนและหลังใช้ระบบ (normalized gain) · การเปรียบเทียบความพร้อมสอบที่ระบบคำนวณกับคะแนนสอบจริง |
| learning model ที่ calibrate แล้ว | parameter ที่ปรับจากข้อมูลผู้ใช้จริง พร้อมรายงานการ calibrate |
| evaluation dataset ของรายวิชานำร่องอื่น | ชุดข้อมูลที่มีเฉลยสำหรับรายวิชานำร่องที่ไม่ใช่คณิตศาสตร์ |
| source code และเอกสารประกอบ | repository ฉบับสุดท้าย เอกสารออกแบบที่ตรงกับระบบจริง และ installation guide |
| รายงานฉบับสมบูรณ์และการนำเสนอ | รายงานโครงงานฉบับสมบูรณ์ สไลด์ และการสาธิตระบบ |
