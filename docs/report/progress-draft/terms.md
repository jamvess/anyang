# รายการคำที่ใช้ในเล่ม

ตกลง 28 พ.ย. (Jam): **ศัพท์เทคนิคที่คนในสาขาใช้เป็นภาษาอังกฤษอยู่แล้ว ใช้คำอังกฤษ** · **คำทั่วไปใช้ภาษาไทย** · คำที่ใช้บ่อยเขียนชื่อเต็มครั้งแรกในเล่ม แล้วใช้ตัวย่อ (ใส่ในรายการคำย่อ) · **ทุกบทใช้คำเดียวกัน** · เพิ่มคำใหม่ในไฟล์นี้ก่อนใช้
