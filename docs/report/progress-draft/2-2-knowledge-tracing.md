## 2.2 การติดตามความรู้และการวางลำดับการเรียนรู้

ระบบติวที่ปรับตามผู้เรียนต้องตอบคำถาม 4 ข้อ ได้แก่ ผู้เรียนเข้าใจแต่ละหัวข้อแค่ไหน เมื่อไรจึงนับว่าผ่าน จะบอกผู้เรียนอย่างไรว่าพร้อมสอบแค่ไหน และควรเรียนหัวข้อใดก่อนหลัง หัวข้อนี้สรุปหลักการที่ใช้ตอบคำถามแต่ละข้อ ส่วนการนำมาใช้ในระบบสรุปไว้ในหัวข้อ 2.6

### 2.2.1 Bayesian Knowledge Tracing

Knowledge tracing คือการประมาณความรู้ของผู้เรียนจากประวัติการตอบคำถาม โดยความรู้ของผู้เรียนเปลี่ยนไปเรื่อยๆ ระหว่างที่ระบบกำลังประเมิน Bayesian Knowledge Tracing (BKT) [Corbett 1995] เป็นวิธีที่ใช้กันแพร่หลาย เช่น ในระบบ Cognitive Tutor [Slater 2018] BKT มองว่าความรู้ในแต่ละทักษะมีสองสถานะ คือ "ยังไม่รู้" และ "รู้แล้ว" ดังรูปที่ 2.1 และใช้ parameter 4 ตัวต่อทักษะ ได้แก่

- p(L₀) ความน่าจะเป็นที่ผู้เรียนรู้ทักษะนั้นอยู่แล้วก่อนทำข้อแรก
- p(G) ความน่าจะเป็นที่ผู้เรียนตอบถูกทั้งที่ยังไม่รู้ (guess)
- p(S) ความน่าจะเป็นที่ผู้เรียนตอบผิดทั้งที่รู้แล้ว (slip)
- p(T) ความน่าจะเป็นที่ผู้เรียนเรียนรู้ทักษะนั้นหลังทำแต่ละข้อ (transit)

รูปที่ 2.1 สองสถานะของ BKT และ parameter ที่เชื่อมระหว่างสถานะ (❓ ต้องวาด)

หลังผู้เรียนตอบแต่ละข้อ BKT ปรับความน่าจะเป็นที่ผู้เรียนรู้แล้ว p(L) ด้วยทฤษฎีบทของ Bayes ตามสมการที่ 2.1 และ 2.2 แล้วเพิ่มโอกาสที่ผู้เรียนเรียนรู้จากข้อนั้นตามสมการที่ 2.3

```
ตอบถูก:   p(L | ถูก) = p(L)(1 − p(S)) / [ p(L)(1 − p(S)) + (1 − p(L)) p(G) ]      (2.1)
ตอบผิด:   p(L | ผิด) = p(L) p(S) / [ p(L) p(S) + (1 − p(L))(1 − p(G)) ]            (2.2)
หลังเรียนรู้: p(L_next) = p(L | คำตอบ) + (1 − p(L | คำตอบ)) p(T)                   (2.3)
```

ระบบที่ใช้ BKT เกือบทั้งหมดถือว่าผู้เรียนผ่านทักษะนั้นเมื่อ p(L) ถึง 0.95 และต้องจำกัดค่า guess และ slip ไม่ให้สูงเกินไป เพราะ model อาจเพี้ยนจนการตอบผิดกลายเป็นหลักฐานว่ารู้มากกว่าการตอบถูก (model degeneracy) ขอบที่ใช้กันคือ p(G) ไม่เกิน 0.30 และ p(S) ไม่เกิน 0.10 [Slater 2018]

BKT ไม่ใช่ model ที่ทำนายผลได้แม่นที่สุด Gervet และคณะ [Gervet 2020] เปรียบเทียบ model หลายแบบบน 9 ชุดข้อมูล และพบว่า logistic regression ทำได้ดีที่สุดในชุดข้อมูลขนาดกลาง Deep Knowledge Tracing (DKT) ซึ่งใช้ neural network ทำได้ดีที่สุดในชุดข้อมูลขนาดใหญ่ ส่วน BKT ทำได้ด้อยกว่าทั้งสองแบบ แต่ BKT มีจุดเด่นที่ parameter ทุกตัวมีความหมายชัดเจนและตั้งค่าเริ่มต้นได้โดยไม่ต้องมีข้อมูลผู้เรียนมาก่อน

### 2.2.2 Mastery Learning และเกณฑ์การผ่าน

Mastery learning คือแนวทางที่ให้ผู้เรียนเรียนหัวข้อหนึ่งจนเข้าใจตามเกณฑ์ก่อนไปหัวข้อถัดไป โดยมีการทดสอบระหว่างเรียนและการแก้ไขจุดที่ยังไม่เข้าใจ Kulik และคณะ [Kulik 1990] รวบรวมผลจาก 108 การทดลอง และพบว่า mastery learning ทำให้คะแนนสอบดีขึ้น โดยได้ผลมากกับผู้เรียนที่อ่อน แต่ต้องใช้เวลาเรียนมากขึ้น

การใช้ BKT เป็นเกณฑ์ผ่านมีข้อจำกัด จากสมการที่ 2.1–2.3 จะเห็นว่า BKT ใช้เพียงว่าผู้เรียนตอบถูกหรือผิด โดยไม่ได้คำนึงถึงความยากของโจทย์ ผู้เรียนที่ตอบโจทย์ง่ายถูกติดกันหลายข้อจึงอาจถึงเกณฑ์ทั้งที่ยังไม่เคยทำโจทย์ระดับข้อสอบ

### 2.2.3 ความพร้อมสอบ (Readiness)

ความพร้อมสอบคือค่าที่ระบบประเมินว่าผู้เรียนพร้อมสำหรับการสอบครั้งหนึ่งมากเพียงใด โดยรวมความเข้าใจของทุกหัวข้อที่อยู่ในขอบเขตการสอบ ผลการทดลองของ Roediger และ Karpicke ในหัวข้อ 2.1.1 แสดงว่าผู้เรียนมักประเมินความพร้อมของตนเองสูงเกินจริง ค่าความพร้อมจึงต้องคำนวณจากผลการทำโจทย์จริง ไม่ใช่จากความรู้สึกของผู้เรียน และต้องตรวจว่าค่าที่คำนวณได้สอดคล้องกับคะแนนสอบจริง Feng และคณะ [Feng 2009] แสดงว่าข้อมูลระหว่างการติว เช่น จำนวนความช่วยเหลือที่ผู้เรียนต้องใช้ ทำนายคะแนนสอบปลายปีได้ดีกว่าการดูเพียงว่าตอบถูกหรือผิด

### 2.2.4 การวางลำดับการเรียนรู้ (Learning Path)

Learning path คือลำดับหัวข้อที่ผู้เรียนควรเรียน โดยหัวข้อที่เป็นความรู้พื้นฐาน (prerequisite) ของหัวข้ออื่นต้องเรียนก่อน การเลือกหัวข้อถัดไปทำได้ทั้งด้วยกฎที่อธิบายได้ และด้วย model ที่เรียนรู้ลำดับจากข้อมูลผู้เรียนจำนวนมาก

ปัญหาหนึ่งของการวางลำดับคือผู้เรียนที่ทำโจทย์ทักษะเดิมซ้ำนานโดยไม่ผ่าน เรียกว่า wheel-spinning ซึ่งนิยามว่าผู้เรียนทำโจทย์ทักษะเดียวกันตั้งแต่ 10 ข้อขึ้นไปโดยยังไม่ถึงเกณฑ์ผ่าน ระบบติว ASSISTments จึงหยุดให้ผู้เรียนทำโจทย์ชุดเดิมต่อเมื่อทำครบ 10 ข้อในวันเดียว [Kai 2018]
