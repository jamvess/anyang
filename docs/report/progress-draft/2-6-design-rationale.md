# 2.6 การนำทฤษฎีมาใช้ในการออกแบบ (Design Rationale) · ร่าง 1

## อยากเล่าอะไร (ก่อนอ่านร่าง)

- ตารางท้ายบทแทนย่อหน้า "ระบบนำมาใช้" ในแต่ละหัวข้อย่อย (Jam 28 พ.ย. ตามแบบตัวอย่าง ENG) · กรรมการเห็นในหน้าเดียวว่าทุกการออกแบบมีที่มา (ตอบคอมเมนต์ข้อ 1 และ 2)
- ใช้เฉพาะ 15 งานที่เหลือหลังตัด · ทุกแถวชี้ไปหัวข้อในบทที่ 3 ที่อธิบายวิธีทำ
- **คอลัมน์สถานะตรวจกับโค้ดแล้ว 28 พ.ย.** และแยกส่วนที่ใช้งานได้ออกจากส่วนที่อยู่ระหว่างพัฒนาในแถวเดียวกัน (ที่มาอยู่ท้ายไฟล์)
- ตาราง 16 แถว ราว 1.5 หน้า · ถ้าต้องลดหน้า รวมแถว 6–7, 8–9 และ 12–14 ได้

## 2.6 การนำทฤษฎีมาใช้ในการออกแบบ (Design Rationale)

ตารางที่ 2.3 สรุปว่าหลักการจากหัวข้อ 2.1 ถึง 2.3 ถูกนำมาใช้ในการออกแบบระบบอ่านยัง? อย่างไร รายละเอียดของการออกแบบแต่ละส่วนอธิบายไว้ในบทที่ 3 และคอลัมน์สถานะแสดงความคืบหน้า ณ สิ้นภาคการศึกษาที่ 1

ตารางที่ 2.3 การนำหลักการจากงานวิจัยมาใช้ในการออกแบบระบบ
